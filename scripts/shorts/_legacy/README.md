# 폐기된 옛 자동화 (참고용 보관)

여기 있는 스크립트는 **더 이상 쓰지 않는다.**

옛 흐름: 무인 실행 → unlisted 업로드 → 사람이 review 대시보드에서 검토 → 수동 공개.
그 정책 주석("Public stays manual", "무인 자동발행은 일부러 뺐다", GPU 신규 생성 금지)
때문에 자동 실행이 3번 연속 실패했다(18편 unlisted 오업로드·중복 재업로드·0편 발행).

**현행 정책은 상위 폴더의 `CLAUDE.md` / `QUOTA_POLICY.md` 를 보라.**
이 폴더의 내용을 판단 근거로 삼지 마라.
