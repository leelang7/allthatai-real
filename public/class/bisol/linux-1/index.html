PART 1. 리눅스의 세계로

1. 리눅스란?

  • 리누스 토발즈(Linus Torvalds)가 만든 컴퓨터 운영체제
  • 자유 소프트웨어와 오픈 소스 개발의 가장 유명한 표본

GNU 프로젝트

유닉스를 여러 회사가 각자 개발하며 소스 코드를 공유하지 않는 문화에 대한 반발로 생겼다. 이름은 GNU's Not Unix의 재귀 약자(바로잡기 B-1 참고).

2. 우분투(Ubuntu)

  • 데비안 GNU/Linux 기반의 데스크탑 환경 리눅스 배포판
  • 쓰는 이유: 개인 PC 환경에 최적화, 간결하고 쉬움, 사용자가 많음, 약 6개월 단위 업데이트
  • 이름: 남아프리카 반투어 "우분투" — 사람들 간의 관계와 헌신에 중점을 둔 윤리 사상
  • 기본 GUI는 GNOME

버전 규칙

  • 1년에 두 번 공개, 번호 = 연도.월 → 19.04 = 2019년 4월
  • LTS(Long Term Support): 장기 지원 버전 — 슬라이드 예시는 14.04 / 16.04 / 18.04 LTS

6. 패키지 관리자 apt & root / sudo

apt = Advanced Packaging Tool. 데비안 계열(Ubuntu 등)에서 소프트웨어 설치·제거·업데이트에 쓴다. 예전의 apt-get과 apt-cache를 합친 것이 apt.

apt기존 명령어기능
apt installapt-get install설치
apt removeapt-get remove제거
apt updateapt-get update패키지 목록 업데이트
apt searchapt-cache search검색
apt showapt-cache show정보 보기

root와 sudo

  • root = 모든 권한을 가진 최고 관리자
  • 일반 사용자로 apt install nano 실행 → Permission denied / are you root? 오류
  • sudo 명령어 형식으로 관리자 권한 획득 → 비밀번호는 우분투 설치 시 정한 내 비밀번호

수업 실습:

sudo apt update        # 패키지 목록 업데이트
sudo apt install tree  # tree 설치

7. 실습: WSL로 Ubuntu 설치

  1. Microsoft Store에서 Ubuntu 검색 후 다운로드
  2. 열기 → 하위 시스템 설치
  3. Windows 기능 켜기/끄기에서 Linux용 Windows 하위 시스템, 가상 머신 플랫폼 체크 (최신 Windows는 관리자 PowerShell에서 wsl --install 한 줄로도 된다)
  4. 재부팅 후 Ubuntu 실행 → 사용자 이름 / 비밀번호 설정
⚠️ 비밀번호를 입력할 때 화면에 아무것도 안 보인다(*도 안 나옴). 입력은 되고 있으니 그냥 치고 Enter.

프롬프트 읽는 법

계정명@컴퓨터이름:~$
  • 계정명 로그인 사용자 · 컴퓨터이름 호스트 이름
  • : 뒤는 현재 위치, ~는 홈 디렉터리(/home/계정명)
  • $ 일반 사용자 / # root ➕

비밀번호를 까먹었을 때

Windows PowerShell에서:

wsl -d Ubuntu -u root   # Ubuntu 배포판에 root로 접속
passwd 내계정명          # 비밀번호 재설정

➕ 배포판 이름은 wsl -l -v로 확인한다. 수업 PC에서는 이름이 Ubuntu(WSL 2)로 나왔다.

PART 2. 리눅스 파일 시스템

8. 파일 시스템 개념

  • 파일 시스템: 저장 장치에서 데이터를 읽고 쓰기 위해 미리 정한 약속, 파일을 저장·검색할 수 있도록 관리하는 방법, 파일 관리 정책
  • 리눅스 파일 시스템 = 디렉터리 + 파일
  • 디렉터리: 파일과 하위 디렉터리를 분류하기 위해 붙이는 이름 공간, 그룹으로 묶은 개념
  • 파일: 물리적인 저장 공간에 저장되는 데이터의 집합
  • 모든 파일과 디렉터리는 루트(/) 아래에 계층적으로 만들어진다 → 트리(tree) 구조
/
├── bin
├── home
│   └── elice
│       ├── 바탕화면
│       ├── 문서
│       └── 다운로드
├── lib
└── usr

tree 명령어로 구조를 확인할 수 있다. 없으면 bash: /usr/bin/tree: 그런 파일이나 디렉터리가 없습니다가 나온다 → sudo apt install tree로 설치 (수업에서 한 실습이 바로 이것).

9. 소유권과 권한

파일 속성 읽기 (ls -al)

권한 숫자 표기

읽기 r=4, 쓰기 w=2, 실행 x=1을 더한다 → rw-r--r-- = 644

권한 변경 chmod / 소유권 변경 chown

chmod 777 elice.txt          # chmod [권한] [파일] → rwxrwxrwx (모든 사용자에게 모든 권한)
chown elice:elice elice.txt  # chown [유저]:[그룹] [파일/디렉터리] → root 권한 필요

13. 🔍 슬라이드 바로잡기

슬라이드에서 틀렸거나 지금 환경과 다른 부분을 모았습니다. 슬라이드와 이 표가 다르면 이 표를 기준으로 보세요.

#슬라이드 내용바로잡기
B-1GNU = "Gnu is not Unix"정확히는 GNU's Not Unix (자기 자신을 포함하는 재귀 약자)
B-2종류 표: 레드햇 .rmp, 데비안 칸에 "레드햇".rpm이 맞다. .deb는 데비안 계열 전용
B-3apt 설명: "데비안 리눅스(.dev)".deb의 오타
B-4"리누스 토발즈가 만든 운영체제"토발즈가 만든 건 커널. 우리가 쓰는 배포판은 리눅스 커널 + GNU 도구 등을 합친 것이라 "GNU/Linux"라고도 부른다(슬라이드도 "데비안 GNU/Linux"라고 씀)
B-5LTS 예시 14.04 / 16.04 / 18.04, "가장 안정적인 버전"예시가 오래됐다. 이후 20.04, 22.04, 24.04 LTS 등이 나왔다. LTS의 핵심은 지원 기간이 길다(표준 5년)는 것. 내 버전은 lsb_release -a로 확인
B-6cd my_project 후 프롬프트가 :/my_project$홈에서 이동했다면 :~/my_project$가 맞다. /my_project는 루트 바로 밑이라는 뜻
B-7디렉터리 구조 그림의 user실제 디렉터리 이름은 /usr
B-8파일 = "주기억장치나 디스크처럼…"파일이 계속 보관되는 곳은 보통 디스크·SSD 같은 보조기억장치. 주기억장치(RAM)는 전원이 꺼지면 내용이 사라진다
B-9>, >>를 cat의 옵션으로 설명cat 옵션이 아니라 셸의 리다이렉션이다. echo hi > a.txt처럼 어떤 명령에도 쓸 수 있다. cat >> 파일은 입력 대기 상태가 되고 Ctrl + D로 끝낸다
B-10mv: "같은 이름이 존재하지 않을 경우 이동"기본 mv는 같은 이름 파일이 있으면 묻지 않고 덮어쓴다. 막으려면 mv -i(확인) 또는 mv -n(덮어쓰지 않음)
B-11find: "-type d 혹은 -type f로 디렉터리나 폴더만"-type d = 디렉터리만, -type f = 일반 파일만
B-12chmod 777 예시실습용일 뿐. 777은 누구나 수정·실행할 수 있어 보안상 위험하다. 보통 파일은 644, 실행 파일·디렉터리는 755를 쓴다
B-13chown "root 권한 필요"인데 예시엔 sudo가 없음실제로는 sudo chown 유저:그룹 파일처럼 쓴다
B-14파일 속성 그림의 권한 rw-r—rrw-r--r-- (9글자: 소유자 3 + 그룹 3 + 기타 3)

14. ➕ 더 알아보기 (슬라이드에 없음)

14-1. 절대 경로 vs 상대 경로 — 자료에서 명시적으로 안 다룸

  • 절대 경로: /로 시작 — /home/user/docs
  • 상대 경로: 현재 위치 기준 — docs, ./docs, ../other
  • . 현재 · .. 상위 · ~ 홈 · cd - 직전 위치

14-2. 주요 디렉터리 (슬라이드 ls / 결과에 나온 것들)

경로용도
/bin, /usr/bin명령어 실행 파일 (which ls로 확인)
/etc시스템 설정 파일
/home일반 사용자 홈
/rootroot 사용자의 홈
/var로그 등 자주 바뀌는 데이터 (/var/log)
/tmp임시 파일
/mnt/c(WSL) Windows C 드라이브

14-3. chmod 기호 방식

chmod u+x script.sh   # 소유자(u)에게 실행(x) 권한 추가
chmod go-w a.txt      # 그룹(g)·기타(o)에게서 쓰기(w) 권한 제거
chmod 755 mydir       # rwxr-xr-x

디렉터리에서 x 권한은 "그 안으로 cd 할 수 있음"을 뜻한다.

14-4. 손에 익히면 좋은 것

  • Tab 자동완성, ↑ 이전 명령, Ctrl + C 실행 중인 프로세스 중단, history
  • man 명령어 — --help보다 자세한 매뉴얼 (q로 종료)
  • mkdir -p a/b/c — 중간 디렉터리까지 한 번에 생성
  • tail -f 로그파일 — 로그를 실시간으로 보기
  • WSL: code .(VS Code로 열기, WSL 확장 필요), explorer.exe .(탐색기로 열기)
  • ps aux, top — 실행 중인 프로세스 보기 (커리큘럼 ④와 연결)
