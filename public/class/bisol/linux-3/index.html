Linux 기초 5 실습 파일

셸 스크립트와 텍스트 처리 — 오늘 실습에 쓰는 연습 데이터

1. 한 번에 준비하기

WSL(Ubuntu) 터미널에 아래 네 줄을 차례로 입력합니다. 실습 준비 완료가 나오면 끝입니다.

mkdir ~/day3
cd ~/day3
wget https://real.allthatai.kr/class/bisol/files/setup.sh
bash setup.sh

2. 만들어지는 것

이름내용
dataset/불량 검사 이미지 폴더 — ok 12장, ng 5장, unknown 3장 (내용이 빈 연습용 파일)
labels.csv파일 이름, 라벨, 작업자 — 10줄
train.log학습 기록: epoch, loss, acc — 5줄

실습하다 데이터가 망가지면 ~/day3 폴더를 지우고 1번을 다시 하면 처음 상태로 돌아갑니다.

3. 파일

setup.sh연습 데이터를 만드는 스크립트 (위 1번에서 받는 파일)↓ day3-data.tar.gz같은 데이터를 묶어 둔 파일 — 7교시 wget · tar 실습용↓

7교시 실습:

wget https://real.allthatai.kr/class/bisol/files/day3-data.tar.gz
tar -xzf day3-data.tar.gz
ls day3-data
